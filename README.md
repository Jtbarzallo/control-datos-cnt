# Control de Datos CNT

App Android de Jorge para controlar el plan de datos del celular (CNT).

## Descargar
👉 **[Descargar ControlDatosCNT.apk](https://github.com/Jtbarzallo/control-datos-cnt/releases/latest/download/ControlDatosCNT.apk)**

Cada vez que se sube un cambio, GitHub compila la app sola y actualiza ese enlace.

## Qué hace
- Cuántos datos te quedan y cuántos días faltan para el vencimiento.
- Cuánto puedes gastar por día para que el plan te alcance (y cuánto llevas hoy).
- Consumo de datos móviles por app.
- No descuenta WhatsApp, Instagram, TikTok y Facebook (ilimitados en el plan CNT). Se puede cambiar tocando cada app.
- Aviso cuando se desconecta el WiFi y empiezas a usar datos.
- Alertas: superaste el consumo del día, te queda 50/25/10/5 %, el paquete vence mañana/hoy.
- Consulta del saldo a CNT con el código USSD y lectura automática de "Le quedan … MB".
- Saldo siempre visible en la barra de notificaciones.

## Instalar (primera vez)
1. Abre el enlace de descarga en el celular y descarga el APK.
2. Ábrelo. Si Android avisa de "orígenes desconocidos", permite instalar desde el navegador.
3. Abre la app y pulsa **Dar permiso** → activa "Control de Datos" en "Acceso a datos de uso".
4. Permite las notificaciones.
5. Registra tu saldo (automático con el código CNT, o a mano) y la fecha de vencimiento.
6. En Xiaomi/Redmi: Ajustes → Apps → Control de Datos → activar **Inicio automático** y batería **Sin restricciones**.
